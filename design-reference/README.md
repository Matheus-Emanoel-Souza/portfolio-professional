# Referência de design — redesign visual (2026-11-16)

Material histórico usado como referência pra ajustar a identidade visual do
site (paleta, tipografia, estilo de componentes). **Não é código do site** —
o `portfolio-professional-redesign.html` é um mockup estático de uma única
página, produzido por outra IA a partir do `index.html` de build antigo;
cortava conteúdo real (Trajetória, 3 dos 5 projetos) que foi **preservado**
na implementação real.

A identidade visual foi aplicada diretamente no código-fonte (`src/styles/tokens.css`,
`src/styles/global.css` e nos componentes/seções), mantendo todo o conteúdo
real existente. Ver commit da aplicação do redesign para o detalhamento.

- `identidade-visual-portfolio.md` — conceito, paleta, tipografia e componentes.
- `portfolio-professional-redesign.html` — mockup estático original (histórico).
- `portfolio-desktop-preview.png` / `portfolio-mobile-preview.png` — previews do mockup.
